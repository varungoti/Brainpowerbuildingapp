# What I Need From You to Deploy Live

I cannot upload/host this into your Supabase project without credentials and project access. Do not paste service-role keys in public chat.

## Minimum

1. Supabase project reference
2. Supabase CLI installed and logged in on your system
3. Permission to run `supabase link`, `supabase db push`, `supabase functions deploy`, and `supabase secrets set`
4. Supabase URL, anon/publishable key, and service-role key entered as secrets

Deploy only:
1. Portal
