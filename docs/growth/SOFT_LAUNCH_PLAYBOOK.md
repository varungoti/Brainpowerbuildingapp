# Soft Launch Playbook

Goal: validate activation, willingness to pay, and retention before scale.

## Cohort Setup

Invite 500-2,000 parents from:

- 7-Day AI-Age Starter Pack leads.
- Creator referrals.
- Parent communities.
- Preschool/clinic waitlists.
- Founder network.

## First-Session Success Path

Every soft-launch parent should:

1. Create or choose child profile.
2. Generate first daily pack.
3. Open one activity.
4. Complete one activity.
5. Create or preview one printable guide.
6. See Family Premium Annual and Family Pro offer.

## Metrics Gates

Greenlight scale only if:

- 40%+ of signups generate a pack.
- 25%+ complete at least one activity.
- 15%+ create or view a printable guide.
- 5%+ start checkout.
- 2%+ purchase in week one.
- 25%+ week-one retention among activated families.

## Offer Tests

- Founder Family Annual: `$49-$79`.
- Founder Family Pro: `$199-$299`.
- Lifetime founding family deal: `$299-$499`, capped, only if cash urgency justifies it.

## Feedback Questions

Ask every beta parent:

1. What did you expect NeuroSpark to do?
2. What was confusing in the first session?
3. Did you understand why the activity was recommended?
4. Would you print or use the parent guide?
5. What would make this worth paying for annually?
6. What would make you recommend it to another parent?
7. What would make you stop using it?
8. Which routine hurts most: bedtime, transitions, tantrums, screen time, school readiness, sibling conflict?

## Completion Criteria

Mark soft launch complete when:

- 100 families have used the app.
- 20 families have paid.
- 30 qualitative feedback notes are recorded.
- P0/P1 issues affecting activation or checkout are closed.
