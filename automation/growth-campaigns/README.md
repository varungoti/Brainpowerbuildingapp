# Growth Campaign Seed Pack

`seed-campaigns.json` defines the first 10 campaigns from the global revenue plan.

Rules:

- Default mode is `dry_run`.
- Approval is required before any outbound action.
- Suppression checks are required before any email/DM.
- Claims must avoid diagnosis, medical outcomes, or guaranteed development.

Use this file to seed `growth_campaigns`, `growth_approval_queue`, or n8n draft workflows after production credentials are configured.
